# 얼음 다리 난투 (Ice Bridge Brawl)

눈 덮인 블록 협곡 위 다리 하나에서 싸우는 브라우저 3D 대전 게임입니다. 칼바람 스타일의 단일 라인 모드에서 영감을 받았고, 영웅과 아이템은 모두 오리지널입니다.

- **AI와 1대1**: 내 영웅과 상대 영웅을 골라 결투
- **칼바람 5대5**: 다리 하나에서 아군 AI 4명과 함께 적 AI 5명과 대전
- **협곡 5대5 (15분)**: 3라인 + 정글 맵에서 포지션(탑·정글·미드·원딜·서포터)을 골라 대전
- **온라인 1대1**: 다음 업데이트 예정

## PC에서 실행하기

설치할 것은 없습니다. 최신 Chrome, Edge 또는 Firefox만 있으면 됩니다.

1. 이 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. 받은 ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **`play.html`을 더블클릭**하면 게임이 열립니다.

- 화면이 버벅이면 메뉴에서 그래픽을 '중간'이나 '낮음'으로 바꾸세요. 왼쪽 위에 FPS가 표시됩니다.
- 예전 2D 버전은 `classic.html`을 더블클릭하면 됩니다.

### 개발할 때

`play.html`은 `tools/build_single.py`가 자동으로 만드는 파일입니다. 코드는 `js/` 폴더에서 고치고 아래처럼 실행하세요.

```
python3 -m http.server      # http://localhost:8000 에서 index.html로 바로 확인
python3 tools/build_single.py   # 고친 내용을 play.html에 반영
```

## 조작

| 키 | 동작 |
|---|---|
| 우클릭 | 이동 / 공격 (누르고 있으면 계속 이동) |

| Q W E R | 스킬. 시전 방식은 메뉴에서 선택: 일반(키 → 좌클릭, 롤 기본), 빠른 시전(키 즉시), 키 떼면 시전. 조준 중 우클릭/Esc로 취소 |

| S | 정지 |
| P | 상점 (칼바람 규칙: 기지를 떠나거나 공격받으면 다음에 죽을 때까지 닫힘) |

| Tab | 점수판 |
| ← → / Space | 카메라 이동 / 복귀 (협곡은 ↑↓도 가능, 미니맵 좌클릭으로 카메라 이동, 우클릭으로 그 지점까지 이동) |
| Esc | 일시정지 |

## 칼바람 규칙

- 분수대에서 회복되지 않고, 체력은 기본 재생(초당 최대 체력의 0.3%)만 있습니다.
- 다리 위 초록 구슬은 밟은 영웅 주변 600 안의 아군 모두에게 체력 18%, 마나 15%를 채워줍니다 (40초마다 재생성).
- 상점은 기지에 있고 공격받지 않았을 때만 열리며, 기지를 떠나거나 공격받으면 다음에 죽을 때까지 닫힙니다.
- 점멸 176초, 눈덩이 47초 (소환사 주문 가속 70 반영). 눈덩이는 고정 피해 20 + 레벨×10, 돌진하면 재사용 대기시간 25% 감소.

## 협곡 규칙 (15분 안팎에 끝나도록 줄인 소환사의 협곡)

- 화면: 바닥은 평평한 2D 그림(라인·정글 길·강·기지), 숲 벽만 솟아 있는 입체 지형 (`js/terrain.js`). 칼바람은 예전 블록 다리 그대로.
- 이동: 우클릭을 누르고 있으면 커서 쪽으로 계속 이동(롤과 같음), 끄는 중에는 새 대상을 잡지 않음. 가만히 있을 때 자동 공격은 몬스터를 건드리지 않음. 영웅은 미니언·몬스터에게 밀리지 않음. 캠프로 돌아가는 몬스터는 대상으로 잡을 수 없음.
- 벽: 맵의 모양(라인·강·정글 길·캠프·기지)에서 만든 부호 거리 하나로 '이동 가능 여부'와 '화면의 벽 높이'를 모두 정함 → 평평하게 보이는 곳은 정확히 다닐 수 있는 곳. 길찾기는 50단위 격자 A*(칸 전체가 열린 칸만 사용) + 직선 구간 검사, 모서리에 걸리면 즉시 다시 길찾기.
- 맵: 블루 기지 왼쪽 아래, 레드 기지 오른쪽 위. 탑·미드·봇 3라인, 가운데를 가로지르는 얼음 강, 라인 사이 숲(벽)과 정글 길. 벽은 지나갈 수 없고, 클릭한 곳까지 길을 찾아 돌아갑니다 (투사체는 벽 위로 날아감).
- 포탑: 라인마다 1개 + 넥서스 앞 포탑 1개. 라인 포탑을 하나라도 부수면 넥서스 포탑을, 넥서스 포탑을 부수면 넥서스를 칠 수 있습니다. 라인 포탑을 부순 라인에는 공성 미니언이 더 자주 나옵니다.
- 10분부터 포탑과 넥서스가 받는 피해가 점점 커집니다 (1분마다 +100%). AI끼리 돌리면 평균 13~14분에 끝납니다.
- 1레벨·500골드로 시작. 분수대 근처에서 체력·마나가 초당 10% 차고, 상점은 기지에서만 열립니다. 미니언 웨이브는 20초부터 30초마다.
- 정글: 진영마다 푸른 정령(90초간 스킬 가속 +20, 마나 재생 2.5배), 붉은 골렘(90초간 평타가 둔화 + 추가 고정 피해), 늑대 무리, 얼음 두꺼비. 몬스터는 캠프에서 멀리 끌려가거나 한동안 못 맞으면 돌아가서 체력을 채웁니다.
- 정글러는 F 강타(몬스터·미니언에게 390 + 레벨×30 고정 피해, 체력 회복), 몬스터에게 주는 피해 +35%, 받는 피해 −40%. 나머지는 F 회복.
- AI 역할: 라이너는 자기 라인에서 막타와 견제, 서포터는 원딜 옆, 정글러는 캠프를 돌다 체력이 낮거나 깊이 들어온 적 라이너를 갱킹. 체력·마나가 부족하거나 돈이 모이면 안전할 때 귀환. 8분부터 미드로 뭉쳐 밉니다.

## 스킬 레벨업과 마나

- 칼바람은 3레벨에서 스킬 포인트 3개(협곡은 1레벨에서 1개)로 시작하고, 레벨이 오를 때마다 1개씩 받습니다.
- Q·W·E는 최대 5랭크(n랭크는 영웅 레벨 2n−1부터), R은 6·11·16레벨에 찍습니다.
- 스킬 피해·회복은 그 스킬의 랭크로 결정되고, 랭크가 오르면 재사용 대기시간이 줄어듭니다.
- 니야·바르칸은 자원이 없고, 나머지는 마나를 씁니다 (재생 초당 2 + 레벨×0.25).
- 메뉴에서 '스킬 찍기: 자동'을 고르면 AI처럼 자동으로 찍습니다.

## 미니언 규칙 (롤과 같은 방식)

- 0.25초마다 반경 500 안에서 대상을 고르고, 지금 대상보다 순위가 높을 때만 바꿉니다.
- 우선순위: 아군 영웅을 공격한 적 영웅(1000 범위 도움 요청) → 아군 영웅을 공격한 적 미니언 → 아군 미니언을 공격한 적 미니언 → 아군 미니언을 공격한 적 포탑 → 가장 가까운 적 미니언 → 가장 가까운 적 영웅 → 구조물
- 영웅이 도망치면 700 밖으로 벗어나거나, 4초간 못 때리거나, 600 넘게 끌려갈 때 포기하고 라인으로 돌아갑니다.
- 포탑을 치는 중에는 영웅끼리의 도움 요청을 무시합니다.
- 협곡에서는 라인에서 480 넘게 벗어난(정글로 들어간) 영웅은 쫓지 않습니다.
- 움직임: 앞을 막는 아군 미니언을 옆으로 비켜 가며 퍼지고(줄 서서 밀어붙이지 않음), 대상에 다가가다 막히면 대상 둘레를 돌아 빈자리로 들어갑니다. 자리 잡고 때리는 미니언은 잘 밀리지 않아 떨림이 줄었습니다.
- 진단: `node tools/minion-diag.mjs 5` (라인 이탈, 정글 진입, 접근 지연, 공격 중 떨림, 겹침)

## 구조

| 파일 | 역할 |
|---|---|
| `js/sim.js` | 게임 규칙 전부 (영웅, 스킬, 아이템, AI, 전투). 화면과 분리되어 Node에서도 돌아감 |
| `js/maps.js` | 맵 정의: 칼바람 다리, 협곡(라인 경로, 벽 격자, A* 길찾기, 포탑·캠프 위치) |
| `js/render3d.js` | Three.js 3D 렌더러 (조명, 이펙트, 파티클). 셰이더를 줄이려고 Lambert/Basic 재질만 사용, 그림자·후처리 없음 |
| `js/blocks.js` | 마인크래프트 스타일 블록 월드 (코드로 그린 16×16 픽셀 텍스처, 블록 종류별 인스턴싱) |
| `js/heroes3d.js` | 영웅 모델: 관절 뼈대, 카툰 셰이딩 + 외곽선, 역할별 공격 동작 (칼 휘두르기·활 당기기·지팡이 찌르기·주먹) |
| `js/models.js` | 미니언·포탑·넥서스 모델 |
| `js/hud.js` | 체력바, 피해 숫자, 하단 패널, 미니맵 등 2D 오버레이 |
| `js/main.js` | 메뉴, 입력, 상점, 게임 루프 |
| `vendor/three/` | Three.js r187 (MIT) |
| `play.html` | 더블클릭용 단일 파일 (자동 생성) |
| `classic.html` | 예전 2D 버전 (파일 하나) |

플레이어 조작은 모두 `cmd(hero, {c:'move'|'atk'|'cast'|...})` 명령으로 처리되므로, 온라인 대전에서도 같은 명령을 네트워크로 보내면 됩니다.

## 테스트

```
node tools/balance.mjs 10 0 2 /tmp/a.json & node tools/balance.mjs 10 1 2 /tmp/b.json & wait
node tools/balance.mjs --merge /tmp/a.json /tmp/b.json   # 모든 1대1 조합 승률표
```

```
node tools/sim-test.mjs 9 1v1   # AI끼리 9판을 끝까지 돌려 결과 표 출력
node tools/minion-test.mjs      # 미니언 행동 점검 (추격 포기, 도움 요청)
node tools/sim-test.mjs 4 5v5
node tools/minion-diag.mjs 5    # 협곡 미니언 진단 (라인 이탈, 정글 진입, 접근 지연, 떨림, 겹침)
node tools/rift-test.mjs 4      # 협곡 AI 대전: 경기 시간, 역할별 행동(라인 체류, 서포터-원딜 거리, 정글 시간, 귀환 수)
```
